# ApexPlanet Data Analytics Internship - Task 4

## Data Storytelling & Statistical Validation

This project is part of the **ApexPlanet Data Analytics Internship - Task 4**.

The objective of this task is to transform the analysis completed in the previous tasks into a clear business story and strengthen key findings using statistical validation.

---

## Project Overview

This project analyzes a retail sales transaction dataset to understand product performance and the factors contributing to differences in sales across products, cities, and time.

The analysis combines:

- Descriptive analytics
- Exploratory data analysis
- Product performance analysis
- Transaction volume analysis
- City-level analysis
- Monthly and quarterly sales analysis
- Statistical hypothesis testing
- Data visualization
- Business interpretation
- Actionable insights

---

## Business Objective

The main objective is to understand the major factors influencing retail sales performance across:

- Products
- Transaction volume
- Transaction value
- Cities
- Time periods

The analysis also uses statistical testing to determine whether an observed difference in average transaction value between selected products is statistically significant.

---

---

## Business Questions

The analysis addresses the following questions:

1. Which products generate the highest sales?
2. Is sales performance influenced more by transaction volume or transaction value?
3. Which products have the highest units sold?
4. Which products have the highest average transaction value?
5. How does product performance vary across cities?
6. Does the observed difference in average transaction value between selected products show statistical significance?
